Hexo 主题推荐

首页Hexo博客搭建指南

Hexo 博客系统的主题有很多选择，你可以在 这里 找到它们。如果你愿意，你还可以自己动手编写一个属于你的主题。

本文主要介绍几个比较好用的主题。

# NexT

NexT 主题的特点是简洁，提供三种外观风格，但同时也功能齐全，而且插件丰富，因此是 Hexo 主题中非常流行的一个。

  • GitHub：https://github.com/next-theme/hexo-theme-next
  • 项目官网：https://theme-next.iissnan.com

# Fluid

Fluid 一款 Material Design 风格的 Hexo 主题，由 Fluid-dev 负责开发与维护。

  • GitHub：https://github.com/fluid-dev/hexo-theme-fluid
  • 项目官网：https://hexo.fluid-dev.com

# Butterfly

Butterfly 是 Jerry 在 hexo-theme-melody 主题的基础上进行开发，支持多种美化魔改、多功能组件及静态部署集成的 Hexo 主题。

  • GitHub：https://github.com/jerryc127/hexo-theme-butterfly
  • 项目官网：https://butterfly.js.org

# Shoka

Shoka 是一个有趣的 Hexo 主题，中文名为 “书架”，可以说是为了笔记阅读而生的主题。Shoka 对 Markdown 的支持很好，并且有很好看的渲染样式。

  • GitHub：https://github.com/amehime/hexo-theme-shoka
  • 演示：https://shoka.lostyu.me
  • 使用说明：https://shoka.lostyu.me/computer-science/note/theme-shoka-doc/

# ShokaX

ShokaX 是基于 Shoka 演变而来的另一个 Hexo 主题，这一点从名字就可以看出来。起因是由于 Shoka 的作者因学业繁忙暂停更新，导致一些 Bug 无人修复，并且缺少文档。于是诞生了 ShokaX 项目，和 Shoka 相比，它有更高的性能、更多的功能、更现代的代码。

  • GitHub：https://github.com/theme-shoka-x/hexo-theme-shokaX
  • 文档中心：https://docs.kaitaku.xyz
  • 演示：https://www.kaitaku.xyz

# Acorn

Acorn 是一个免费且开源的 Hexo 主题，和其他主题不一样，Acorn 是适用于企业站点的主题，可适用于中小型企业门户或工作室等展示类网站的简单建设。

  • GitHub：https://github.com/zhwangart/hexo-theme-acorn
  • 项目官网：https://acorn.imaging.xin
  • 演示：https://saintree.cn
