# 添加 MathJax

MathJax 是一个 JavaScript 引擎，用来显示网络上的数学公式，它支持大部分的主流的浏览器。

有些 Hexo 主题（如 NexT）内部已经集成了 MathJax，只需要编辑 themes/next/_config.yml 配置文件，找到 math 配置项，配置为 enable: true 即可启用。
