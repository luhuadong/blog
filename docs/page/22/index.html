空调匹数与面积

# 空调匹数是什么意思 空调的匹数表示空调的输入电功率，1 匹 = 735w，根据空调的能效比可知制冷量，例如，能效比 3.0，那么一匹空调制冷量是 2205 瓦。 国家标准规定，房间空调器的大小按制冷量参数标注。比如一台型号为 KFR-22GW 的空调，其中数字 “22” 即表示这台空调的制冷量为 2200W 的空调器，可以简称为 “22 型”。 可是很多人都不这么叫，而是叫多少多少 “匹”，其实叫 “匹” 是完全错误的。“匹” 是一种功率单位，1 匹（马力）=735W（瓦），过去在日本的口头叫法把输入功率为 735W 空调叫 1 匹空调，输入功率为 1470W 的空调称为 2 匹空调..
