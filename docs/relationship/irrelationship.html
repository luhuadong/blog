# 什么是假性亲密关系

假性亲密关系（Irrelationship）是指很多人在情感里的连结处于很浅层的状态，然后又处于不作为的状态。

《假性亲密关系》一书中有这样一段话：

有些感情，外看一切安好，内看却发现只是两个孤独的人，演着孤独的戏。

从广义上来说，一切低质量的爱情，都可以称之为 “假性亲密关系”。
