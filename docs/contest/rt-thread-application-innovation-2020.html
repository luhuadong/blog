# 大赛要求

  • 开发者基于 RT-Thread 开发物联网创新型应用或者终端产品。
  • 基于主办方提供的硬件或者自备硬件均可，RT-Thread 支持主流芯片架构如 ARM Cortex-M、MIPS、X86、C-Sky、RISC-V，几乎所有开发者手头开发板（如 STM32、LPC 系列、i.mx rt 系列、其他国产 32 位 MCU）均可运行 RT-Thread。
  • 如需使用到云服务，推荐使用 UCloud 云资源，可为参赛者提供有效期半年的 800 元 UCloud 云资源使用金用于参赛作品的云服务；也可自由选择其他云服务非强制要求。
  • 代码和文档开源。
